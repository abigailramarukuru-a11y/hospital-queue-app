# Hospital Queue Management System

A Flask-based web application designed to reduce long hospital queues by allowing patients to book appointments and helping staff manage patient flow.

## Features
- Patient booking
- Department-based queue management
- Search patients
- Edit patient details
- Serve patients
- View queue statistics

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- Bootstrap

## Purpose
This project aims to improve hospital service efficiency by reducing waiting time and organizing patient queues digitally.
